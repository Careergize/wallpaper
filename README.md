# Nabas — Walls with soul

A responsive wallpaper storefront built with React 19, Tailwind CSS 4 and Vite.

## Run

npm install
npm run dev

## Production

npm run build
npm run preview

Features: collection filtering, live search, product details, persistent saved designs and sample bag, room inspiration, a wallpaper area calculator, local enquiry drafts, and responsive mobile navigation.

This is a frontend concept. Products, colours and prices are illustrative. Sample ordering, newsletter signup and enquiries do not connect to a backend. Enquiries are explicitly saved locally. Connect your catalogue, contact details, mailing provider and payment service before launch. The botanical and floral SVG patterns are custom project assets; interior photos from Unsplash are included locally. Fonts load from Google Fonts.
